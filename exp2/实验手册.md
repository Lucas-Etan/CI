# 实验 02：洗衣机模糊推理系统

## 1. 实验内容、目的与最终应用

### 1.1 先看几个实际例子

很多控制问题没有清晰的“一刀切”边界。例如衣物污渍程度为 6.5 时，它可能既“有些中等”又“有些严重”。本实验会构建一个能够处理这种连续过渡的模糊推理系统。

* **模糊推理系统**：用 0～1 的程度表示一个输入属于若干语言概念的强弱，再通过规则合成连续输出的系统。

完成后，我们的程序可以处理以下情形：

- 洗衣时间建议：输入污渍程度 6.5、油污程度 8.0，系统计算各自属于“低、中、高”的程度，并给出约 47.81 分钟的建议。
- 空调控制：温度既“偏暖”又“较热”时，不必突然把风速从低档跳到高档，而可以平滑地调整。
- 自动浇水：土壤“略干”和天气“较热”共同决定浇水时长，而不是只比较一个固定阈值。
- 图像曝光调整：画面亮度和对比度都存在程度差异，可以通过规则得到连续的曝光补偿量。

本实验采用 Mamdani 模糊推理完成洗衣时间计算。

* **Mamdani 模糊推理**：一种常见规则推理方法，通常依次执行输入模糊化、规则强度计算、输出截断、规则聚合和解模糊。

### 1.2 实验内容

我们会在已经创建好的骨架中完成：

1. 实现三角形和左右肩形隶属度函数。
2. 把两个 0～10 的精确输入转换成“低、中、高”三个隶属度。
3. 用 9 条规则覆盖两个输入的组合。
4. 用最小值计算规则强度，用最大值聚合规则输出。
5. 用离散重心法得到 0～60 分钟的精确洗涤时间。
6. 生成 JSON 结果和三联图，并在最终输出中显示本人学号。

* **隶属度**：0～1 之间的数，表示某个值属于一个模糊概念的程度；0 表示完全不属于，1 表示完全属于，中间值表示部分属于。

* **解模糊**：把规则聚合后得到的模糊输出转换成一个可直接执行的精确数值，例如 47.81 分钟。

### 1.3 实验目的

完成实验后，我们应能：

- 解释精确集合边界与模糊集合连续过渡的区别。
- 手工核对一个输入点在相邻隶属函数上的取值。
- 说明规则前件为何使用 `min`，多条规则输出为何使用 `max`。
- 用重心法把聚合曲线转换为洗涤时间。
- 结合规则强度和结果图解释最终建议，而不是只报告一个数字。

* **模糊集合**：允许元素以不同程度属于集合的表示方法；它描述的是概念边界的渐变，不等同于随机概率。

## 4. 理解配置中的隶属函数与规则

### 4.1 三角形与肩形函数

普通三角形由左端点 `a`、顶点 `b`、右端点 `c` 决定。在 `b` 处隶属度为 1，在 `a` 和 `c` 处为 0，两侧线性变化。

* **三角形隶属函数**：用两条线段描述隶属度先升后降的函数，参数少、直观，适合入门实验。

当 `a=b` 时，左侧不再上升而形成左肩；当 `b=c` 时形成右肩。

* **肩形函数**：在论域一侧保持最高隶属度、另一侧逐渐下降的函数，适合表达“很低以下都算低”或“很高以上都算高”。

`config.py` 已给出输入三组参数：

```python
INPUT_TERMS = {
    "low": (0.0, 0.0, 5.0),
    "medium": (2.5, 5.0, 7.5),
    "high": (5.0, 10.0, 10.0),
}
```

这段配置不会单独输出结果。它表示 0 完全属于 `low`，5 完全属于 `medium`，10 完全属于 `high`，相邻概念之间有重叠。

### 4.2 九条规则为什么能够覆盖输入

两个输入各有三个语言项，因此一共有 `3 × 3 = 9` 种组合。配置中的规则例如：

```python
("medium", "high", "long")
```

它表示 `IF stain=medium AND grease=high THEN time=long`。规则表覆盖了全部九种组合，因此论域内任一输入至少会激活一条规则。

* **规则覆盖**：规则集合能够处理目标输入范围中的各种组合，不会留下完全没有输出的空白区域。

## 5. FILL-01：实现隶属度函数

NumPy 会让一段公式同时作用于一组采样点，这称为向量化。

* **向量化**：让数组运算一次处理多个元素，减少显式 Python 循环，并使数学表达更接近公式。

**理论说明：** 上升边在普通三角形中计算 `(x-a)/(b-a)`，左肩时直接取 1；下降边同理。对两条边逐元素取较小值形成三角形，再裁剪到 `[0,1]`，就能同时处理论域外点、普通三角形和肩形。

* **逐元素运算**：数组中的每个位置独立执行同一计算；`np.minimum` 返回两个数组对应位置的较小值。

将 `membership.py` 的 FILL-01 替换为：

```python
rising = (
    np.ones_like(values)
    if a == b
    else (values - a) / (b - a)
)
falling = (
    np.ones_like(values)
    if b == c
    else (c - values) / (c - b)
)
return np.clip(np.minimum(rising, falling), 0.0, 1.0)
```

**实践方式：** 保存文件后，用三个关键点检查普通三角形，再检查左肩：

```powershell
python -c "import numpy as np; from membership import triangular; print(triangular(np.array([0, 2.5, 5]), 0, 2.5, 5)); print(triangular(np.array([0, 2.5, 5]), 0, 0, 5))"
```

**运行验证：** 应输出：

```text
[0. 1. 0.]
[1.  0.5 0. ]
```

**QA：** 如果出现除零警告，说明没有为 `a==b` 或 `b==c` 单独处理肩形。

**QA：** 如果输出包含负数或大于 1 的数，检查最后是否使用 `np.clip(..., 0.0, 1.0)`。

## 6. 模糊化、规则合成与解模糊

### 6.1 FILL-02：把精确输入模糊化

模糊化会把一个精确值转换成各语言项的隶属度字典。

* **模糊化**：计算精确输入对各输入模糊集合的隶属度，是模糊推理的第一步。

**理论说明：** 对 `INPUT_TERMS` 的每组参数调用 `triangular`。函数接收数组，因此把单个值放入长度为 1 的数组，再取第一个结果并转为普通 `float`，便于后续写入 JSON。

将 FILL-02 替换为：

```python
return {
    term: float(triangular(np.array([value]), *points)[0])
    for term, points in INPUT_TERMS.items()
}
```

**实践方式：** 检查输入 6.5：

```powershell

```

**运行验证：** 结果应类似：

```text

```

这说明 6.5 同时部分属于 `medium` 和 `high`，两者不要求相加为 1。

**QA：** 如果得到 `numpy.ndarray` 而不是数字，检查是否使用 `[0]` 取出数组元素并调用 `float`。

### 6.2 FILL-03：计算规则激活强度

规则前件中的“且”使用较小隶属度。例如污渍属于中等的程度为 0.4、油污属于高的程度为 0.6，这条规则的强度为 `min(0.4, 0.6)=0.4`。

* **规则激活强度**：一条模糊规则当前成立的程度；数值越大，该规则对输出的影响越强。

**理论说明：** Mamdani 推理常用 `min` 表示模糊逻辑“且”。这会让较弱的前提成为整条规则的上限，符合“所有条件都要满足”的直觉。

将 FILL-03 的占位值替换为：

```python
strength = min(
    stain_mu[stain_term],
    grease_mu[grease_term],
)
```

### 6.3 FILL-04：截断并聚合输出

程序先用规则强度截断对应的输出隶属函数，再把当前结果与已有结果逐点取最大值。

* **截断**：把输出隶属函数高于规则强度的部分压到该强度，表示这条规则最多只能贡献到它自身的成立程度。

* **聚合**：把多条已激活规则的输出合成一条最终模糊输出曲线；本实验逐点取最大值。

**理论说明：** 骨架已经用 `np.minimum(strength, output_shape)` 完成截断。FILL-04 只需用 `np.maximum` 把截断曲线合并到累计曲线，不能用普通加法，否则重叠规则会把隶属度加到 1 以上。

将 FILL-04 替换为：

```python
aggregated = np.maximum(aggregated, clipped)
```

### 6.4 FILL-05：重心法解模糊

离散重心法把每个时间采样点看作位置，把对应隶属度看作权重。

* **重心法**：用 `Σ(位置×权重)/Σ权重` 计算模糊输出的平衡位置，是常见的解模糊方法。

**理论说明：** 先计算权重总和，若总和为 0 就说明没有规则产生输出，应明确报错；否则计算加权平均并转为普通浮点数。

将 FILL-05 替换为：

```python
denominator = float(np.sum(membership))
if denominator <= 0.0:
    raise ValueError("聚合输出为空，无法执行解模糊")
return float(np.sum(x * membership) / denominator)
```

## 11. 综合 QA

### Q1：为什么 6.5 同时属于中和高？

两个隶属函数在 5～7.5 区间重叠，这正是模糊集合表达连续过渡的方式。它并不表示输入随机地属于某个类别。

### Q2：为什么只有两条规则显示出来？

程序计算了全部 9 条规则，但终端只显示强度大于 0 的规则。默认输入对 `low` 的隶属度为 0，因此包含 `low` 的规则不会影响结果。

### Q3：`np.arange` 为什么在终点加上 `OUTPUT_STEP`？

`np.arange` 默认不包含停止值。加一个步长可以让 60 分钟进入采样范围；本实验步长 0.25 能整除 60，终点稳定。

* **采样点**：用有限个离散位置近似连续论域的计算点；步长越小，曲线越细，但计算量也会增加。

### Q4：运行后弹出空白窗口怎么办？

确认 `matplotlib.use("Agg")` 位于导入 `matplotlib.pyplot` 之前。本实验应直接保存图片，不需要交互窗口。

### Q5：输出图的中文为何没有使用？

图中采用英文标签，可以避免不同 Windows 电脑缺少同一种中文字体而产生方框。终端和 JSON 仍使用中文说明。
